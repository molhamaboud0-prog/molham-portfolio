# Molham Aboud — Portfolio

Personal portfolio (resume-first gallery): **E‑commerce** (React Native app — [separate repo](https://github.com/molhamaboud0-prog/ecommerce-mobile)), **FlavorHub** & **CareVisit** UI/UX previews.

## Open the site

```bash
cd portfolio-site
npm install   # optional, for screenshot scripts only
npm run serve
```

Open **http://localhost:3456/portfolio-site/index.html**

Or double-click **Molham Portfolio.command** on the Desktop.

## Structure

| Path | Description |
|------|-------------|
| `portfolio-site/` | Portfolio website (HTML/CSS/JS) |
| `Ui Ux Resturant/FlavorHub/` | Restaurant app UI/UX + live preview |
| `Ui Ux Clinecs/` | Clinic patient UI/UX + live preview |
| `Ecommerce/Mobile/` | Full Expo app (tracked in [ecommerce-mobile](https://github.com/molhamaboud0-prog/ecommerce-mobile)) |
