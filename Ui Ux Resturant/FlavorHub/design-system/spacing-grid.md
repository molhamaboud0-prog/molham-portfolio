# Grid & Spacing

- **Baseline:** 4px — all gaps and padding use multiples of 4.
- **Screen horizontal margin:** 20px (compact 16px for dense lists).
- **Safe area:** respect iOS top 59px / bottom 34px in prototypes.
- **Layout grid on frames:** Columns 4, margin 20, gutter 16 (optional for alignment).

## Common stacks (Auto Layout)

| Pattern | Gap | Padding |
|---------|-----|---------|
| Screen body vertical | 16 | 20 horizontal |
| Card internal | 12 | 16 |
| Button row | 12 | — |
| List items | 8 | 16 vertical per row |
| Section header to content | 12 | — |
