# Food images & icons (Figma)

Each menu item uses:

1. **Photo** — Pexels crop `640×432` (cards), see `DISH_MEDIA.pexels` in [`preview/menu-data.js`](../preview/menu-data.js)
2. **Icon badge** — Emoji overlay bottom-end matching dish type

## Figma workflow

- Place **Image fill** from Unsplash URL in spec (or export from preview capture)
- Add **48×48** rounded badge with emoji on top of image
- Hero dish detail: **780×400**, same photo + badge
